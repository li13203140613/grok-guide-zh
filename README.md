**这是一份写给中文用户的 Grok 使用指南，包括会员价格和怎么选、每周用量规则、国内能不能用、Grok Bot 教程、图片被拦怎么办、取消订阅和退款、常见报错排查，以及 Grok Imagine 提示词范例。所有内容都对照 xAI 和 X 的官方页面核对过，每篇文末附官方链接。**

> 最后核对：2026-10-16｜本仓库非官方，与 xAI、SpaceXSI、X Corp. 无关联

2026 年 10 月起，Grok 会员改成了 **The X Subscription**（Plus / Premium / Super / Ultra 四档），SuperGrok 不再对新用户单独出售；2026 年 6 月起，付费用户的“每日次数”改成了“每周共享额度”。网上很多教程还停留在旧规则，这份指南按新规则重新整理。

## 这份指南的写法

- **只写能核实的事实。** 价格、菜单路径、规则都来自 x.ai、docs.x.ai、help.x.com 等官方页面；官方没有公开的内容会直接写明“官方没有公开说明”，不编数字。
- **说人话。** 菜单名写成「中文意思（English 原文）」，方便对照英文界面找。
- **不写违规内容。** 不提供越狱、破限、绕过审核的方法：官方使用规则明确禁止，违反可能被封号。
- **会过时。** Grok 更新很快，每篇都标了核对日期。看到和官方页面不一致的地方，请以官方为准，也欢迎提 Issue 告诉我们。
