# Grok 和 ChatGPT、Gemini 对比：会员价格和区别

**Grok 和 ChatGPT、Gemini 三家都有免费版和多档付费会员。Grok 的 The X Subscription 是 $8、$30、$100、$200 四档；ChatGPT 是 Go、Plus、Pro；Google 的 Gemini 是 AI Plus、AI Pro、AI Ultra。三家的价位很接近，但每档包含的东西不一样。2026-10-16 在中国区 App Store 搜，三家都没有面向个人的官方 App。本文只比价格、档位和包含的功能，不评价哪家回答更好。**

> 最后核对：2026-10-16｜依据：三家官方价格页、美国区 App Store（链接见文末）｜本文非官方

## Grok 和 ChatGPT 按价位怎么对上

**结论：$8、约 $20～30、$100、$200 这几个价位，Grok 和 ChatGPT、Gemini 基本都有对应档位，但价位接近不等于内容一样。**

| 价位 | Grok | ChatGPT | Gemini |
|---|---|---|---|
| 入门 | Plus $8 | Go $8.00 | AI Plus $4.99 |
| 常用 | Premium $30 | Plus $19.99 | AI Pro $19.99 |
| 重度 | Super $100 | Pro $100 | AI Ultra $99.99 |
| 最高 | Ultra $200 | Pro $200 / $500 | AI Ultra $199.99 |

官方推荐的选法各写各的，Grok 官方 FAQ 的意思是：新 AI 用户选 Premium，每天用 agent 的选 Super，重度用户选 Ultra，Plus 适合 AI 用得少的社交创作者。各档细节见 [Grok 套餐区别](grok-taocan-qubie.md) 和 [Grok 价格](grok-jiage.md)。

## Grok 和 ChatGPT、Gemini 会员各包含什么

**结论：三家都不只卖聊天，各自打包了不同的东西。**

- **Grok**：Grok、Cursor 和 X 权益归进同一个订阅，按档位提供。Plus 起有 Cursor 和 X 认证勾；Premium 起有 Grok Bot 和完整 X Premium+ 权益（要连接个人 X 账号）。所有功能共用一个每周用量池。
- **ChatGPT**：Go 额度比免费版高，但可能包含广告；Plus 加了高级推理、项目、自定义 GPT 和更高 Codex 用量；Pro 加了 Dot 全天候智能体和无限且更快的生图。
- **Gemini**：每档都带 Google 存储空间，从 15 GB 到 20 TB 起；AI Pro 带 Jules、Antigravity 编程工具和 YouTube Premium Lite；AI Ultra 带 YouTube Premium 个人版。

编程方面，Grok 和 ChatGPT 各有一套：ChatGPT 的 Plus 有更高的 Codex 用量，Grok 从 Plus 起含 Cursor。Grok 这边要注意：Cursor 里的第三方模型（比如 Claude、GPT）不在套餐用量内，按 API 标价单独付费，详见 [Cursor 和 SuperGrok 区别](cursor-supergrok.md)。

## Grok 和 Gemini 哪个好：本文为什么不下结论

**结论：回答质量没有官方可以核实的依据，本文不评价哪个模型更好。**

Grok 和 ChatGPT、Gemini 的模型都在频繁更新，网上的“谁更聪明”大多是个人测试，换个问题、换个时间结果就不同。想在 Grok 和 ChatGPT 之间选，比较实际的做法是：

1. 三家都有免费版，先用同一批你自己的问题各试几天。

3. 最后看价位和付款方式能不能接受。

## 常见问题

### Grok 和 ChatGPT 哪个便宜？

Grok Plus 是 $8/月，ChatGPT Go 在 App Store 列表里也是 $8.00（官网按月标价）；常用档 Grok Premium $30/月，ChatGPT Plus 是 $19.99（App Store 列表价）。都是美国价、不含税，以官网为准。

### 三家会员价格对比里，哪家有最便宜的付费档？

按美国价，Google AI Plus 的 $4.99/月最低。不同地区价格可能不同。

### Grok 会员能直接用 ChatGPT 或 Claude 吗？

Grok 订阅不包含 ChatGPT、Claude 这类第三方模型的额度。在 Cursor 里可以调用第三方模型，但按 API 标价单独付费，不占套餐用量。

### ChatGPT Pro 为什么有三个价格？

美国区 App Store 列表里有 Pro 100、Pro 200、Pro 500 三项，官网写 Pro 有 3 档用量可选。
