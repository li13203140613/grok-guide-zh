# SuperGrok Heavy 是什么？和 Plus、Lite 的区别

**SuperGrok Heavy 是 xAI 在 The X Subscription（X 统一订阅）之前卖的老订阅里最高的一档。2026 年 10 月起新用户已经买不到，只能买 Plus、Premium、Super、Ultra 四档新套餐；已经订了的老用户可以继续用、继续续费。官方没有公开它和 SuperGrok、Plus、Lite 之间具体差多少用量和功能。**

> 最后核对：2026-10-16｜依据：官方页面和美国区 App Store（链接见文末）｜本文非官方

## Grok Heavy 是什么：官方只说了这么多

结论：官方对它的描述只有一句话，没有公布具体用量。

- 官方 Grok 使用指南（企业版部分）里写：SuperGrok 是“标准访问，更高的配额和高级功能”；如果组织有升级版许可，可以用 SuperGrok Heavy，获得“更强的性能”。
- 除此之外，**官方没有公开 Lite、SuperGrok、Plus、Heavy 各自的用量数字和功能差别**。
- 网上流传的“Plus 有 1080p 视频”“Heavy 是多智能体”等说法，没有找到官方来源，本文不采用。

## 老套餐价格：App Store 列表价

结论：官方网页现在不公布老套餐价格，能查到的只有 App Store 的内购列表。

2026-10-16 查看美国区 App Store 官方 Grok App（开发者 X Corp.）的“App 内购买项目”，列出的价格如下：

| 项目 | App Store 列表价（美元） |
|---|---|
| SuperGrok Lite | $10.00 |
| SuperGrok | $30.00 |
| SuperGrok（另一项） | $300.00 |
| SuperGrok Plus | $100.00 |
| SuperGrok Heavy | $300.00 |
| 额外额度 | $5 / $20 / $50 / $100 |

注意：

- 这是 App Store 列表价，不含税；App Store 列表**没有写明每一项的扣费周期**，比如 $300 的那一项 SuperGrok 是什么周期，官方没有说明。官方 FAQ 里提到过有“SuperGrok Heavy 年付订阅”，但没有公布年付价格。

## SuperGrok Plus 和 Heavy 区别，以及 Lite

结论：唯一有官方依据的区别，是 Grok Bot 用量的等级。

Cursor 帮助页给出了把老订阅关联（link）到 Cursor 账号后，Grok Bot 用量属于哪一档：

| 老订阅 | Grok Bot 用量等级 |
|---|---|
| SuperGrok Lite | **不含 Grok Bot** |
| SuperGrok、X Premium+ | 和 Cursor Pro 同一档 |
| SuperGrok Plus | 和 Cursor Pro+ 同一档 |
| SuperGrok Heavy | 和 Cursor Ultra 同一档 |

- Lite 用户想用 Grok Bot，要先升到 SuperGrok、SuperGrok Plus 或 SuperGrok Heavy，再去关联。
- 关联只是给 Cursor 账号加 Grok Bot 用量，不是一个 Cursor 套餐；关联后不能解除、不能转到别的 Cursor 账号。
- Cursor 套餐和关联用量不叠加，用两者里每周用量更多的那个。比如已经关联了 Heavy，再买 Cursor Ultra 也不会多出 Grok Bot 用量。

## SuperGrok 还能买吗：老用户续费还是换新

结论：新用户买不到；老用户目前可以继续使用和续费，换不换自己决定。

如果想换到新套餐，先看清这几条：

1. **换了不能撤销**，客服也改不回去。
2. 老套餐结账时被取消，**按剩余时间自动退款**到原付款方式，不抵扣新套餐，新套餐全价收。
3. 已有老订阅的**只能在网页上换**（accounts.x.ai/unify），手机 App 里暂时不能换。
4. 苹果里买的 Grok 会自动取消并向苹果申请退剩余时间，批不批由苹果决定；Google Play 买的，换完要去 Google Play 确认已停止续费。
5. 换过去以后，Grok Bot 用量改从每周共享用量池里扣；原来关联给 Cursor 的 SuperGrok Heavy 用量不属于新套餐。

新套餐里用量最大的是 Ultra（Plus 的 50 倍），各档区别见 [Grok 套餐区别](grok-taocan-qubie.md)。

## 常见问题

### SuperGrok Heavy 要怎么取消？

网页直接付的，打开 grok.com/dashboard → Billing & invoices（账单和发票）取消，老用户也可以打开 grok.com/?_s=billing；苹果买的在 iPhone 设置 → 订阅里取消。至少在续费前 24 小时操作。

### 新套餐的 Ultra 就是以前的 Heavy 吗？

官方没有这样说。官方只在 Grok Bot 用量上说过 Heavy 和 Cursor Ultra 同档，没有给 SuperGrok 老套餐和新四档的对照表。

### SuperGrok Lite 是什么？

App Store 列表价 $10.00 的老档位，不含 Grok Bot。官方没有公开它的具体用量。
