# Cursor 和 SuperGrok 有什么区别？Grok 会员送不送

**Cursor 是一个 AI 写代码工具，SuperGrok 是 Grok 的老会员，原本是两份订阅。2026 年 10 月起两者合进 The X Subscription（X 统一订阅），新套餐 Plus 及以上每档都包含它。但老 SuperGrok（包括 Heavy）不送任何 Cursor 套餐，关联后只会多出 Grok Bot 用量。**

> 最后核对：2026-10-16｜依据：xAI 和 Cursor 官方页面（链接见文末）｜本文非官方

## 一张表看懂：老 Cursor Pro、老 SuperGrok、新 Premium

结论：老 SuperGrok 是 Grok 会员，老 Cursor Pro 是编程工具会员，新 Premium 把两样合在一起。

| 项目 | 老 Cursor Pro | 老 SuperGrok | 新 Premium |
|---|---|---|---|
| 价格（美元） | $20/月 | $30（App Store 列表价） | $30/月 |
| 新用户能买吗 | 不能 | 不能 | 能 |
| 编程工具会员 | 是 | 不含 | 含，模型编程用量至少是老 Pro 的 2 倍 |
| Grok 会员 | 不含 | 是 | 含 |
| Grok Bot | 有 | 关联后有，和老 Pro 同一档 | 有，从每周共享用量池扣 |
| Claude、GPT 等第三方模型 | 有单独的月度用量池 | 不适用 | 不含额度，按 API 标价从预付余额扣 |
| 用量怎么算 | 两个每月用量池 | 官方没有公开具体数字 | 一个每周用量池，和 Grok 共用 |

价格不含税，以官网为准。老 SuperGrok 的价格官方网页现在不公布，上表用的是美国区 App Store 列表价。

## SuperGrok 和 Cursor Pro 区别

结论：一个是 Grok 会员，一个是编程工具会员，互相不包含。

- 老 Cursor Pro 包含：无限 Tab 补全、Bugbot、Cloud Agents、Automations、Origin 和 SDK，用量按月重置，超额月底结算。
- 老 SuperGrok 是 Grok 聊天、生图等的会员，本身不是编程工具套餐。
- 两者唯一的交集是 Grok Bot：官方说老 Pro、SuperGrok、X Premium+ 在 Grok Bot 用量上是同一档。
- 两份订阅可以同时有效、各扣各的钱，买一个不会取消另一个。

## Grok 会员送 Cursor 吗

结论：新套餐送，老 SuperGrok 不送。

- **新的 The X Subscription**：Plus、Premium、Super、Ultra 每档都写明包含 Cursor，免费版不含。
- **老 SuperGrok、SuperGrok Plus、SuperGrok Heavy、X Premium+**：不包含编程工具套餐。官方原话是关联只是“用量授予（usage grant），不是 Cursor 套餐”。
- 关联前没有 Cursor 套餐的，关联后也照样没有，只是多了 Grok Bot 用量。
- 关联是永久的，不能解除，也不能转到别的账号，所以要先确认登录的是对的账号。

## SuperGrok Heavy 送 Cursor Ultra 吗

结论：不送。两者只是在 Grok Bot 用量上同一档。

- Cursor 帮助页原文：Ultra 和 SuperGrok Heavy 是同一档；Pro+ 和 SuperGrok Plus 是同一档。
- 这里说的“同一档”只指 Grok Bot 的用量，不代表 Heavy 用户能拿到编程工具 Ultra 套餐。
- 关联用量和编程工具套餐**不叠加**，Grok Bot 用两者里每周用量更多的那个。官方举例：已经关联了 Heavy，再买 Cursor Ultra 也不会多出 Grok Bot 用量。

## Cursor 里能用 Grok Bot 吗

结论：Grok Bot 有自己的桌面和手机 App，用 Cursor 账号登录，用量也记在这个账号上。

- 去 x.ai/bot 下载 Grok Bot 的桌面或手机 App，登录时选“Sign in with Cursor”。官方文档没有说明能不能在编辑器里直接调用 Grok Bot。
- 谁有 Grok Bot 用量：新套餐 Premium、Super、Ultra；老 Cursor Pro、Pro+、Ultra 和团队版；关联了 SuperGrok、SuperGrok Plus、SuperGrok Heavy 或 X Premium+ 的账号。
- 新 Plus 和免费版不含，SuperGrok Lite 也不含。
- Grok Bot 有免费试用：一笔用量额度，7 天期限，长任务可能一次用光，用掉不补。

- 换过去以后账单在 grok.com/dashboard/billing 管理，超额用充值（top-ups），不再月底结算。
- 苹果 App Store 里买的编程工具会员，换完苹果还会继续扣费，要自己去 iPhone 设置里取消。

## 常见问题

### 买了新 Premium，还要另付 Cursor 的钱吗？

基础编程用量已经包含；用 Claude、GPT 这类第三方模型时，按 API 标价从预付余额里扣。

### 已有 Cursor Pro，再买 SuperGrok 能叠加 Grok Bot 用量吗？

不能叠加。Pro 和 SuperGrok 同一档，Grok Bot 用两者里更多的那个；关联 SuperGrok Plus 才会升到 Pro+ 那一档。

### 关联错了 Cursor 账号怎么办？

官方说关联不能解除、不能转移，只能在关联前确认好账号。
