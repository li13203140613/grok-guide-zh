## 现在的 Grok 会员是怎么卖的？

一句话：**Grok、Cursor（一个 AI 写代码工具）和 X Premium（推特会员）合成了一个订阅。**

以前 Grok 的会员有好几种买法：在 grok.com 买 SuperGrok，在 X 上买 X Premium / Premium+，写代码的人再单独买 Cursor。2026 年 10 月起，xAI 把这些合并成了一个订阅，名字叫 **The X Subscription**，由 X Subscription Corp. 负责销售。

合并之后有三个变化，普通用户最需要知道：

1. **买一份会员，Grok 和 X 的权益一起拿到。** 付费档位只要连接自己的个人 X 账号，就会带上对应的 X 会员权益。
2. **用量变成每周一个总额度。** Grok 的聊天、生图、语音、Grok Bot，还有 Cursor 里的 Grok 模型，都从同一个每周额度里扣。详见 [Grok 次数用完了怎么办](grok-usage-limits.md)。
3. **网上很多价格已经过时。** 比如“SuperGrok $30/月”“X Premium+ $40/月”都是旧价格，现在新用户买不到这些了。

## 四档会员价格一览

下表是 x.ai/pricing 官方页面上的个人价格，单位美元，**不含税**，结账时可能会加税。

| 档位 | 月付 | 年付 | 每周用量 | Grok Bot |
|---|---|---|---|---|
| Free（免费） | $0 | $0 | 有限 | 没有 |
| Plus | $8 | $80（约 $7/月） | 基础量 | **没有** |
| Premium | $30 | $300（约 $25/月） | Plus 的 4 倍 | 有 |
| Super | $100 | $1000（约 $84/月） | Plus 的 15 倍 | 有 |
| Ultra | $200 | $2000（约 $167/月） | Plus 的 50 倍 | 有 |

团队版只有 Premium、Super、Ultra 三档，按人头收费，每人 $30 / $100 / $200，Plus 不能买团队版。更大的公司可以联系官方销售谈企业版。

价格可能调整，下单前以 [x.ai/pricing](https://x.ai/pricing) 为准。

## 每一档具体多了什么？

**Free（免费）**
- Grok 聊天和 agent（自动执行任务）有次数限制，官方没有公布具体数字。
- 生图有限，**不能生成视频**。
- X 上能正常发帖、回复、关注。

**Plus：$8/月**
- 有一个共享的每周用量池。
- 能用 Grok 聊天、语音（Voice）、生图（Imagine）、搭应用（Build）。
- 可以调用 Grok API（API 按模型价格另外计费）。
- 包含 Cursor。
- X 上：认证勾、时间线广告更少、创作者工具、高级数据分析。
- **不含 Grok Bot。**

**Premium：$30/月（官方标注“最受欢迎”）**
- 用量是 Plus 的 4 倍。
- **包含 Grok Bot**：一个带云端电脑、能自己去网站上办事的 AI 助手，详见 [Grok Bot 是什么、怎么用](grok-bot-guide.md)。
- 最新的 Grok 模型，聊天回复更快。
- AI 图片和视频生成。
- 代码托管、AI 代码审查、云端 agent 和自动化（写代码的人用得上）。
- X 上：大部分页面没有广告、优先挑选 @用户名、回复更容易被看到，相当于完整的 X Premium+ 权益。

**Super：$100/月**
- Premium 的全部内容，用量是 Plus 的 15 倍。
- 高峰时段优先使用模型，人多的时候不容易排队。

**Ultra：$200/月**
- Super 的全部内容，用量是 Plus 的 50 倍。
- 最早用上所有新产品和新模型。

**所有档位都不包含的：** Cursor 里的第三方模型（比如 Claude、GPT）要按 API 价格单独付费。

## 我该选哪一档？

官方在价格页给的建议是：**刚开始用 AI 的选 Premium；每天都让 agent 干活的选 Super；重度用户选 Ultra；Plus 适合主要在 X 上做内容、AI 用得不多的人。**

换成具体场景，可以这样对照：

| 你的情况 | 建议 |
|---|---|
| 主要刷推特，想要认证勾、少看广告，偶尔问问 Grok | Plus |
| 想认真用 Grok 聊天、写东西、生图生视频 | Premium |
| 想用 Grok Bot 帮你自动处理邮件、表格、网页上的事 | 至少 Premium |
| 以前是 X Premium+ 用户，想保留全部 Premium+ 权益 | Premium 或以上 |
| 每天大量生成视频，或让好几个 Bot 同时干活 | Super |
| 工作中重度依赖，Super 也经常不够用 | Ultra |

拿不准的话，可以先买 Premium 的月付，用一周后到 设置 → 用量（Usage）里看看额度消耗得多快，再决定升级还是降级。网页上**升级是马上生效的**，结账页会显示剩余费用怎么处理。

## SuperGrok 和 X Premium 还能买吗？

**新用户买不到了。** 官方文档写得很清楚：新用户只能从 The X Subscription 的几个档位里选。

但已经在用的不受影响：

- 已经订阅 SuperGrok、SuperGrok Plus、SuperGrok Heavy 的，可以继续用、继续续费。
- 已经订阅 X Premium、X Premium+ 的，也一样。
- 是否换成新套餐，**完全自己决定**，官方原话是“Switching is optional（换不换是可选的）”。

所以如果你在别处看到“SuperGrok Heavy 多少钱”“SuperGrok 怎么订阅”的教程，那是写给老用户的，对新用户已经不适用。

## 老用户要不要换成新套餐？

换之前先弄清楚这几条官方规则：

1. **换完不能撤销。** 官方说合并账号是永久的，客服也帮不了你改回去。
2. **老套餐会按剩余天数自动退款。** 退款退回原来的付款方式，不会抵扣新套餐，新套餐要全价付。到账时间看银行。
3. **已有老订阅的，只能在网页上换**，手机 App 里暂时换不了。入口：从 Grok 或 X 开始的去 accounts.x.ai/unify；有付费 Cursor 的去 cursor.com/unify；X Premium 用户也可以在 x.com 的订阅设置里点升级。
4. **苹果手机上订的要特别留心。** 苹果 App Store 里买的 Grok、Grok Bot、X Premium，换套餐时会自动取消，并替你向苹果申请退剩余时间（批不批由苹果决定）。但如果你是在苹果上买的 **Cursor**，换完苹果还会继续扣钱，一定要自己去 iPhone 设置里取消。
5. **Google Play 订的**，换完去 Google Play 看一眼，如果还显示会续费，就手动取消。

什么情况下值得换？比如你现在用的 SuperGrok 不含 Grok Bot，又想用 Bot；或者你同时付着 X Premium+ 和 SuperGrok 两份钱，想合成一份。如果现在用得好好的，不换也没问题。

## 怎么付款？

官方网页结账支持这几种方式：

- 银行卡（信用卡、借记卡）
- Apple Pay
- Google Pay
- Link（Stripe 的快捷付款）

有些付款方式只在部分国家能用，结账页面显示什么就能用什么。**官方没有列出支付宝和微信支付。**

另外几点要注意：

- 订阅默认**自动续费**，想停掉要在续费前至少 24 小时取消，见 [Grok 怎么取消订阅](grok-cancel-subscription.md)。
- 付款原则上不退款，法律另有规定的地区除外。
- 官方在价格页 FAQ 里明确说：订阅**只由 X Subscription Corp. 直接销售，不授权任何经销商或第三方卖家**，通过其他渠道买的订阅可能被暂停或终止。

## 常见问题

### Grok 会员一个月多少钱？

最便宜的付费档 Plus 是 $8/月，最常用的 Premium 是 $30/月，Super $100/月，Ultra $200/月，都是美元价，不含税。买年付大约能省两个月的钱。

### Grok 免费版能用吗？

能用。免费版可以聊天、少量生图，但次数有限，而且不能生成视频，也没有 Grok Bot。官方没有公布免费版的具体次数。

### X Premium 和 Grok 会员现在是一回事吗？

新用户来说基本是一回事。买 The X Subscription 的付费档，并连接你的个人 X 账号，就会拿到对应的 X 会员权益：Plus 档有认证勾和创作者工具，Premium 及以上相当于完整的 X Premium+。

### SuperGrok Heavy 还有吗？

新用户买不到了。已经订阅的老用户可以继续用。新套餐里用量最大的是 Ultra（Plus 的 50 倍）。

### Plus 能用 Grok Bot 吗？

不能。官方文档写明 Grok Bot 只包含在 Premium、Super、Ultra（以及团队版、企业版）里。

### 买了会员，Grok API 是免费的吗？

不是。付费档位可以调用 Grok API，但 API 按模型价格单独计费，也不占用会员的每周额度。
