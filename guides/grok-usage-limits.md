# Grok 次数用完了怎么办？2026 每周用量和重置规则

**Grok 付费会员现在没有“每天多少次”的说法了：从 2026 年 6 月起，聊天、生图、语音、Build、Grok Bot 共用一个每周额度，每周重置一次，具体重置时间在 设置 → 用量（Usage）里能看到。用完之后，免费档的聊天和语音还能继续用；想马上接着用付费功能，可以买额外额度（最少 $5，目前只能在网页上买），或者升级到更高的档位。**

## Grok 的次数限制现在是怎么算的？

**结论：一个每周总额度，所有功能一起用。**

以前 Grok 是每个功能分开限制：聊天一天多少条，生图一天多少张。常见的情况是，生图额度用光了，聊天的额度却还剩很多，用不上。

2026 年 6 月起，官方改成了**每周共享用量池**：

- 付了费就有一个每周额度，Chat（聊天）、Imagine（生图生视频）、Voice（语音）、Build（搭应用）、Grok Bot 都从这里扣。
- 如果你同时用 Cursor 写代码，Cursor 里的 Grok 模型也从同一个池子里扣。
- 怎么分配你自己决定，可以全部拿来生图，也可以全部拿来聊天。
- **每周重置一次**，官方说这样“某一天用得特别多，也不会把整个月的额度用光”。

各档位的额度大小，官方是按倍数写的：

| 档位 | 每周额度 |
|---|---|
| Free | 有限（官方没公布数字） |
| Plus（$8/月） | 基础量 |
| Premium（$30/月） | Plus 的 4 倍 |
| Super（$100/月） | Plus 的 15 倍 |
| Ultra（$200/月） | Plus 的 50 倍 |

各档位的完整区别见 [Grok 会员多少钱？四档价格和区别](grok-pricing-plans.md)。

## 为什么我的额度掉得特别快？

**结论：不同功能扣的量差很多，生视频和长时间任务最费额度。**

官方原话的意思是：不同产品消耗的算力不一样，扣的额度也不一样。聊一句天扣得很少；生成一段高质量视频，或者跑一个很长的编程任务，扣得多得多。

所以如果你发现额度一下子掉了一大截，先回想一下最近是不是：

- 连着生成了好几段视频；
- 让 Grok Bot 跑了一个很长的任务；
- 用 Build 或 Cursor 做了较大的编程任务。

到 设置 → 用量（Usage）里看“按产品的占比”，就能知道额度主要花在了哪里。

还有一个和视频有关的规则：**720p 视频用到你所在档位的上限后，会自动降到 480p。** 如果你发现视频突然变模糊了，多半就是这个原因，不是出了故障。

## 怎么看还剩多少额度、什么时候重置？

网页和手机 App 都能看：

1. 打开 Grok，进入 **设置（Settings）**。
2. 点 **用量（Usage）**。

这个页面会显示：

- 一个进度条，显示这周已经用了百分之多少；
- 按产品（API、Build、Chat、Imagine、Voice）分别用了多少；
- **下次重置的日期和时间**；
- 额外额度（Extra Usage Credits）的余额，如果你买过的话。

重置时间每个人可能不一样，**以这个页面上显示的为准**。网页端也可以在 grok.com/dashboard 里看用量和充值设置。

## 额度用完了还能用吗？

**能，只是付费功能会先停下来。**

官方说明，每周额度用完之后：

- **付费功能暂停**，等到下次重置再恢复。
- **免费档的聊天（Chat）和语音（Voice）还能用。** 这部分是单独计算、单独重置的，和你的每周额度互不影响。
- 官方特别强调这“不是硬性停止”，你还有三个选择：
  1. **买额外额度（Extra Usage Credits）**，买完马上就能接着用；
  2. **升级到更高的档位**，拿到更大的每周额度；
  3. **打开自动充值（Auto Top Up）**，余额低了自动补。

## 买额外额度还是升级会员？

先看额外额度的规则：

- **目前只能在网页上买**，手机 App 里暂时买不了。
- 最少买 $5，在网页的 用量（Usage）页面购买。
- 买完立刻到账，等每周额度用完之后才开始扣。
- 一般**购买一年后过期**。
- 按标准价计算，**比会员套餐里的额度贵**。

自动充值（Auto Top Up）默认是关的，要自己打开。打开后可以设一个每月上限，避免一不小心扣太多钱。

**官方的建议很直接：**

- 偶尔超一次，买点额外额度就行，比较方便；
- 如果**经常**超额，升级档位更划算，同样的钱能用的量多得多。

举个例子：你是 Plus 用户，每周都要买额外额度才够用，那不如直接升级 Premium，额度是 Plus 的 4 倍。网页上升级是马上生效的。

## 免费版限制是多少？

**官方没有公布具体次数，只写了“有限（Limited）”。**

能确定的是：

- 免费版可以聊天，也能少量生图；
- 免费版**不能生成视频**；
- 免费版**没有 Grok Bot**；
- 免费版的聊天和语音额度单独计算、单独重置。

网上流传的“免费版每天能问多少条”“每 2 小时能生成几张图”，都不是官方数字，而且官方随时可能调整，参考价值不大。

## 网上说的“2 小时恢复”还准吗？

**基本已经过时了。**

搜“Grok 限制重置时间”，很多文章写的是“滚动窗口，大约 2 小时恢复一部分”。这类说法有两个问题：

1. 来源是第三方根据 Reddit 网友经验汇总的，**不是官方数字**；
2. 写的是 2026 年 6 月改成每周额度**之前**的情况。

现在付费用户以 设置 → 用量（Usage）里显示的重置时间为准。

另外，网上还有一类“解除次数限制”的方法，教你用技巧绕过额度。**官方使用规则明确禁止绕过频率限制和安全措施，违反可能被暂停或封号**，不建议尝试。

## 常见问题

### Grok 限制多久重置一次？

付费会员每周重置一次，具体日期和时间在 设置 → 用量（Usage）里看。免费档的聊天和语音额度有自己的重置时间，官方没有公布具体规则。

### Grok 怎么看剩余额度？

设置 → 用量（Usage），网页和手机 App 都有，能看到用了百分之多少、各功能占比和下次重置时间。

### 额度用完了会自动扣钱吗？

不会，除非你自己打开了自动充值（Auto Top Up）。自动充值默认是关闭的。

### 额外额度能在手机上买吗？

目前不能，只能在网页上买。官方说手机 App 内购以后会支持。

### 为什么我生成的视频变成 480p 了？

720p 视频用到所在档位的上限后，会自动降为 480p。等额度重置，或者升级档位。

### 用 Grok API 会扣会员额度吗？

不会。Grok API 单独按模型价格计费，不占会员的每周额度。
