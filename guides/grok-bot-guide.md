## Grok Bot 是什么？和 Grok 聊天有什么区别？

**结论：聊天是“回答你”，Bot 是“替你去做”。**

在 grok.com 里和 Grok 聊天，它给你的是一段文字：一份草稿、一个答案、一个建议，剩下的事你自己去做。

Grok Bot 不一样。官方的说法是“你可以长期留着的 AI 队友”，它有三个特点：

1. **有自己的电脑。** 每个账号配一台**持久的云端电脑**，里面有浏览器、文件系统和终端。Bot 在这台电脑上打开网站、登录你的工具、填表、整理文件，事情是在真实的工具里办完的，不是只给你一段草稿。
2. **能积累经验。** 每个 Bot 有名字、有固定的工作，会保留你的偏好、它负责的角色和以前工作的摘要，不用每次都从头交代。不过官方也提醒：重要的决定，要让 Bot 去查最新的资料，别只靠它的记忆。
3. **会自己接着干。** 活儿在云端跑，**你把电脑合上、手机锁屏，它也照样干**。需要你确认的时候再来找你。

官方 FAQ 原话：Grok Bot“和 grok.com 或 Grok 手机 App 里的 Grok 不是同一个东西”。

## Grok Bot 能做什么？

官方举的例子大多是工作上的重复活：

| Bot 角色 | 负责的事 |
|---|---|
| 销售外呼 | 研究客户、挑出合适的联系人、用你的语气写好邮件草稿等你审 |
| 招聘 | 按岗位要求找候选人、说明为什么合适、写好联系话术 |
| 广告投放 | 拉取各个广告的花费和效果，对照预算给出调整建议 |
| 报销管理 | 整理每周报销、对上发票、标出缺信息的单子 |
| 收件箱管理 | 清理邮件、把回复草稿排好，等你明天确认再发 |
| 参谋长 | 每天汇总邮件、日历、会议记录里跟你有关的事 |

还有几个让它更好用的功能：

- **可以同时建好几个 Bot。** 一个管项目、一个管对外联系、一个管系统维护，它们能并行工作，还能在群聊里互相交接任务。
- **教一次就会。** 你带着 Bot 把一个流程走一遍，它可以存成一个“技能（skill）”，再设成“例程（routine）”按时间表自动跑，比如每周一早上出周报。
- **能在 X 上叫它。** 在帖子或回复里 @bot，你的主 Bot 会把这条帖子当成任务接下来。这个功能要先把 X 账号连到 Grok 账号，**而且还没有对所有地区开放**。

网上流传的“让 Grok Bot 帮你订机票、整理推特书签、清理收藏”，从原理上说属于“在网站上替你操作”的范围，但官方文档没有专门讲这些用法，效果要你自己试。至于“订错票官方会赔”这类说法，**官方页面里找不到任何依据**，别当真。

## Grok Bot 多少钱？哪个会员能用？

**结论：最低要 Premium，$30/月。**

| 档位 | 价格（美元/月，不含税） | 有没有 Grok Bot |
|---|---|---|
| Free | $0 | 没有 |
| Plus | $8 | **没有** |
| Premium | $30 | 有 |
| Super | $100 | 有，用量是 Plus 的 15 倍，高峰时段优先 |
| Ultra | $200 | 有，用量是 Plus 的 50 倍，最早体验新产品 |
| Teams / Enterprise | 按席位 | 有 |

需要知道的几点：

- Grok Bot **没有单独的价格**，它的用量和 Grok 聊天、生图、语音一样，从会员的**每周共享额度**里扣，超出的部分按 token 成本计费。规则见 [Grok 次数用完了怎么办](grok-usage-limits.md)。
- Bot 一直在云电脑上干活，跑长任务比聊天费额度得多。打算让好几个 Bot 天天干活的，官方建议选 Super。
- 以前通过 SuperGrok、SuperGrok Heavy 连 Cursor 用 Grok Bot 的老用户，可以继续用；换成新套餐后，Bot 用量改从每周共享额度里扣。
- 各档位完整区别见 [Grok 会员多少钱](grok-pricing-plans.md)。

## Grok Bot 怎么下载？

官方下载页是 **x.ai/bot**。

**电脑端：**

| 系统 | 选哪个安装包 | 怎么看自己是哪种 |
|---|---|---|
| macOS | Apple 芯片版 或 Intel 版 | 苹果菜单 → 关于本机：显示“芯片”就是 Apple 芯片，显示“处理器”就是 Intel |
| Windows | x64 版 或 Arm64 版 | 设置 → 系统 → 系统信息 → 系统类型 |
| Linux | x64 或 Arm64，有 .deb、.rpm、AppImage | 终端输入 `uname -m`：x86_64 是 x64，aarch64 是 Arm64 |

macOS 安装：打开下载的镜像文件，把 Grok Bot 拖进“应用程序”文件夹；第一次打开时如果系统要你确认，点“打开”。

**手机端：**

- iPhone / iPad：App Store 里的「Grok Bot」，开发者 **X Corp.**，需要 iOS 18 或以上。
- Android：Google Play 里的 Grok Bot（包名 `ai.x.grok.bot`），需要 Android 9 或以上。

手机和电脑连的是**同一批 Bot、同一台云电脑**，在电脑上布置的任务，可以在手机上看进度、点批准。

注意：中国区 App Store 搜不到官方 Grok 系列 App，名字相似的都不是官方的，辨别方法见 [国内能用 Grok 吗](grok-china-access.md)。

## 第一次使用：4 步上手

**第 1 步：登录。** 打开 App，点「Sign in（登录）」，在弹出的浏览器里完成认证，再回到 App。Grok Bot 用的是 **Cursor 账号体系**，登录页显示 Grok 或 xAI 的标志是正常的。老 SuperGrok 用户在 App 提示时点「Link Grok Account」关联账号，关联完再点「Finished Linking? Refresh My Status」刷新。

**第 2 步：跟着引导走一遍。** App 会介绍 Bot、共享电脑和例程，并问你平时用哪些工具。这些回答**只用来给你推荐合适的 Bot，不会自动连接或修改你的工具**。云电脑在后台准备，第一次要等几分钟。

**第 3 步：建第一个 Bot。** 在「Meet a future teammate（认识你未来的队友）」里选一个推荐的，或点「Create your own（自己创建）」，填三样东西：

- **名字**：简短好记，比如“小周报”。
- **主要工作**：只写一件，比如“每周整理销售数据”。
- **怎么干**：写清楚它该怎么做、什么不能碰，比如“只读数据，不准改任何设置，结论先写最重要的一条”。

官方建议：**一个 Bot 只管一类事**，比一个什么都管的 Bot 好用得多。工作多了再点「New → Create new Bot」加新的。

**第 4 步：给它第一个任务。** 直接打字，或者用语音：电脑上按 Cmd/Ctrl + D 语音输入，手机上点「Start dictation」；也可以点「Start voice chat」直接语音对话。

## 怎么给 Bot 布置任务才好用？

官方总结了一个好任务要写清楚的 5 件事：

1. **要什么结果**：做完是什么样子？
2. **用哪些东西**：要用哪些网站、应用、文件、聊天记录？
3. **有什么限制**：什么不能做，做之前要先问你？
4. **交付什么**：最后给你一份表格、一份草稿，还是一段总结？
5. **什么时候停**：做到哪一步停下来等你确认？

一个中文例子：

> 帮我整理这周的报销。从报销系统里导出本周所有单子，和邮箱里的发票一张张对上，把缺发票、缺分类的单子标出来，给每个负责人写一封催补材料的邮件草稿。最后给我一张汇总表和这些草稿，**不要发送任何邮件，也不要改报销状态**。

官方建议的上手顺序是：**先让它做“只看、只整理”的活**，你检查结果、纠正它；结果稳定了，再存成技能；在第二批数据上也测过没问题，最后才设成定时例程。凡是会对外产生影响的动作，一直保留“先问我”。

## 安全吗？要注意什么？

Grok Bot 能登录你的账号、替你操作，所以安全问题要比聊天认真得多。官方文档里有几条很重要：

- **所有 Bot 共用一台电脑。** 文件、浏览器、登录状态都是共用的。官方原话是：隔离是按用户的，不是按 Bot 的，**不同 Bot 之间不算安全隔离**。放到这台电脑上的东西，你所有的 Bot 都能拿到。
- **密码、验证码自己输入。** 遇到登录密码、两步验证码、验证码图片、付款确认，Bot 应该把电脑交给你：点「Take over（接管）」，自己操作完点「I'm done（完成）」，再告诉 Bot 继续。**不要在聊天里把密码、验证码发给 Bot。**
- **该批准的再批准。** 要批准的操作会显示具体内容，有「Allow once（这次允许）」「Always allow（以后都允许）」「Deny（拒绝）」三个选项。看不懂它要干什么的，先别点允许，让它用大白话解释清楚。
- **这几类事情一定要设成“先问我”**：发消息或邀请、发布内容、购买和转账、删除或覆盖数据、改权限、接受法律条款。
- **可以开自动审核（Auto Review）。** 在 设置 → General → Auto-review 里加规则，比如“发任何外部邮件前先问我”。不要设“浏览器里什么都允许”这种宽泛的规则。
- **隐私方面**：云电脑在传输和存储时都加密，可以选择不让数据参与训练，敏感操作执行前会先经过自动审核。

## Bot 卡住了怎么办？

**看起来不动了：**

1. 看侧边栏和对话里显示的状态。
2. 打开云电脑，看它是不是停在某个页面上等你。
3. 看看有没有它发来的提问、待批准的操作、登录或验证码请求。
4. 方向不对就发一句话纠正它；想让它停下就直接发“Stop now”。

**某个网站一直要求登录：** 接管电脑，自己登录，完成两步验证或验证码，确认页面已经登录成功，再交还给 Bot，让它从当前页面接着做。

**云电脑连不上：** 按这个顺序试，越往后越“重”：

1. 点「Retry（重试）」或重新打开对话；
2. 重启 Grok Bot App；
3. 出现「Recover computer（恢复电脑）」时点它；
4. 设置 → Computer → 「Update Bot's Computer（更新 Bot 的电脑）」；手机上是 设置 → Bot → Bot Computer → Reset Computer；
5. **最后才用 Reset（重置）**，它会恢复到上一次保存的状态，最近没同步的工作可能会丢。

**第一次打开一直显示正在设置：** 首次准备和系统更新要几分钟，进度还在动就耐心等；不动了就重试、重启 App、检查更新。

**提示额度用完：** 到用量和账单（Usage & Billing）里看额度，见 [Grok 次数用完了怎么办](grok-usage-limits.md)。

## 常见问题

### Grok Bot 免费吗？

不免费。Grok Bot 包含在 Premium（$30/月）及以上的会员里，Plus（$8/月）和免费版都没有。

### Grok Bot 和 Grok 有什么区别？

Grok 是聊天助手，给你答案和草稿；Grok Bot 有自己的云端电脑，能登录你的工具、在网站上替你把事情做完。官方明确说两者不是同一个东西。

### 电脑关了 Grok Bot 还会工作吗？

会。活儿在云端电脑上跑，关掉 App、合上笔记本、锁上手机，都不影响正在进行的任务和定时例程。

### Grok Bot 支持 Windows 吗？

支持。Windows 有 x64 和 Arm64 两个版本，另外还有 macOS、Linux、iPhone、iPad、Android 版。

### Grok Bot 能用中文吗？

能用中文给它布置任务。手机 App 的设置里可以选语言（Language），选「System」就跟随手机系统语言，官方说手机上可选的语言比电脑版少。

### 一个 Bot 能同时做好几件事吗？

可以同时思考、调用工具、处理文件，但一个 Bot 在自己的屏幕上同一时间只能做一件“操作电脑”的任务。事情多就多建几个 Bot，让它们并行。
