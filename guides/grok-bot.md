# Grok Bot 是什么？价格、下载和使用教程

**Grok Bot 是 xAI 推出的“AI 队友”。每个账号配一台持久的云端电脑（浏览器、文件夹、终端），它能登录你的工具、在网站上替你把多步骤的活干完，需要拍板时再回来问你。它和 grok.com 里的聊天不是一个东西。The X Subscription 的 Premium（$30/月起）、Super、Ultra 都包含它，Plus 和免费版不含；新用户有一笔免费试用额度。下载地址是 x.ai/bot。**

> 最后核对：2026-10-16｜依据：xAI 官方页面和 Grok Bot 官方文档（链接见文末）｜本文非官方

## Grok Bot 是什么，和 Grok 聊天有什么区别

**结论：聊天是“回答你”，Bot 是“替你去做”。**

官方 FAQ 原话是，Grok Bot 和 grok.com、Grok 手机 App 里的 Grok 不是同一个东西。区别主要有三点：

1. **有自己的电脑。** 云端电脑一直在，Bot 在上面打开网站、填表、整理文件，结果是在真实工具里办完的。
2. **能积累上下文。** 官方说它能保留稳定的偏好、负责的角色和以前工作的摘要，不用每次从头交代。但重要决定要让它去查最新资料，别只靠它记住的内容。
3. **你关机它照样干。** 活在云端跑，可以建好几个 Bot 并行、全天候工作，比如一个管项目、一个管对外联络。

## Grok Bot 价格：哪些会员能用

**结论：最低要 Premium，美国价 $30/月或 $300/年，不含税，以 x.ai/pricing 为准。**

| 档位 | 月付 | 有没有 Bot | 用量 |
|---|---|---|---|
| Free | $0 | 没有 | 有限 |
| Plus | $8 | 没有 | 基础 |
| Premium | $30 | 有 | 是 Plus 的 4 倍 |
| Super | $100 | 有 | 是 Plus 的 15 倍 |
| Ultra | $200 | 有 | 是 Plus 的 50 倍 |

几点要知道：

- Grok Bot 没有单独标价，用量和聊天、生图一样，从**每周共享用量池**里扣，超出部分按 token 成本计费，规则见 [Grok 使用限制](grok-shiyong-xianzhi.md)。
- Grok Bot 跑长任务比聊天消耗的用量多得多。各档完整区别见 [Grok 价格](grok-jiage.md)。
- 老 SuperGrok 用户关联 Cursor 拿到的 Bot 用量可以继续用；换成新套餐后，改从每周共享池里扣。

### Grok Bot 免费试用怎么算

官方 Cursor 帮助页写明有免费试用：它是**一笔用量额度**，同时有 **7 天期限**。额度按 agent 步骤和 token 扣，不按发了几条消息算，一个大任务可能一次用光，用掉的不补。试用不会自动变成付费套餐。官方建议先拿小任务试，看清每个任务用多少再放大。

## Grok Bot 下载：电脑和手机版

官方下载页是 **x.ai/bot**：

- **电脑**：macOS（Apple 芯片 / Intel）、Windows（x64 / Arm64）、Linux（.deb / .rpm / AppImage）。
- **iPhone**：App Store 里开发者为 X Corp. 的那款，需要 iOS 18 或以上。
- **Android**：Google Play 包名 `ai.x.grok.bot`，需要 Android 9 或以上。

手机版和电脑版 Grok Bot 连的是同一批队友、同一台云电脑。2026-10-16 按 App 编号在中国区 App Store 查询，官方 Grok 和 Grok Bot 都查不到，辨别方法见 [Grok 国内能用吗](grok-guonei.md)。

## Grok Bot 怎么用：4 步上手

1. **登录**：点「Sign in with Cursor（用 Cursor 账号登录）」，在浏览器里完成认证再回到 App。老 SuperGrok 用户按提示关联 Grok 账号。
2. **跟着引导走**：Grok Bot App 会问你平时用哪些工具，只用来推荐队友，不会自动连接你的工具。
3. **建第一个 Bot**：在「Meet a future teammate（认识未来的队友）」里选推荐的，或点「Create your own（自己创建）」，起名字、给一个主要工作、写清楚该怎么干。官方建议一个只管一类事。
4. **布置任务**：打字，或在电脑上按 Cmd/Ctrl+D 语音输入。

好的任务描述写清 5 件事：要什么结果；用哪些网站、应用、文件；什么不能做、做之前先问；最后交付什么；做到哪一步停下来等你确认。流程演示一遍后，它能存成“例程（routine）”按计划自动跑。

## Grok Bot 安全吗，卡住了怎么办

**结论：所有 Grok Bot 共用一台云电脑，官方明说不同 Bot 之间不算安全隔离。**

- 文件、浏览器、登录状态都是共用的，别把不想让所有 Bot 看到的东西放上去。
- 网站要登录或要验证码时，你接管云电脑自己输入，确认成功再交还，别在对话里发密码。
- 隐私方面，云电脑传输和存储都加密，可以选择不参与训练，敏感操作执行前有自动审核。

看起来不动了：看侧边栏状态，打开云电脑看是不是停在某页等你，或直接发“Stop now”让它停。云电脑连不上就依次试：重试或重开对话 → 重启 App →「Recover computer（恢复电脑）」→ 设置 → Computer →「Update Bot's Computer」。最后才用 Reset，它会丢掉最近没同步的内容。

## 常见问题

### Grok Bot 免费吗？

不算免费产品，但有免费试用：一笔用量额度加 7 天期限，长任务可能一次用完。正式使用要 Premium 及以上，Plus 和免费版不含。

### 电脑关了 Grok Bot 还会工作吗？

会。任务在云端电脑上跑，合上笔记本、锁上手机都不影响进行中的任务和定时例程。

### 能在 X 上叫 Grok Bot 干活吗？

可以在 X 上 @bot 让你的 Bot 接任务，需要先在 grok.com 把 X 账号连上，而且还没有对所有地区开放，见 [推特 Grok 怎么用](grok-tuite.md)。

### Grok Bot 支持 Windows 吗？

支持，有 x64 和 Arm64 两个版本，另有 macOS、Linux、iPhone、Android 版。
