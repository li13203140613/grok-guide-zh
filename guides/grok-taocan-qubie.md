# Grok 套餐区别：Plus、Premium、Super、Ultra 一张表看懂

**Grok 套餐区别主要在三处：用量（Premium、Super、Ultra 分别是 Plus 的 4、15、50 倍）、有没有 Grok Bot（Plus 没有，Premium 起才有）、X 会员权益（Plus 只有认证勾等基础权益，Premium 起是完整 X Premium+）。视频生成、代码托管这些功能也从 Premium 开始。下面先看总表，再逐项说。**

> 最后核对：2026-10-16｜依据：官方页面（链接见文末）｜本文非官方

## 用量的区别：4 倍、15 倍、50 倍是什么意思

结论：Grok 套餐区别首先在用量上。所有付费档共用一个每周用量池，档位越高池子越大。

- Chat、Imagine、Voice、Build、Bot 以及 Cursor 里的 Grok 模型都从同一个池子里扣，每周重置。
- 不同功能扣得不一样：聊一句扣得少，生成高清视频、长时间编程任务扣得多。
- 免费版官方只写“有限”，没有公布具体次数。
- Cursor 里的第三方模型（如 Claude、GPT）不算在池子里，按 API 标价另付。

## 功能的区别：Grok Bot 和视频从哪档开始

结论：这一项是 Grok 套餐区别里最关键的分界线，Plus 和 Premium 差的就是它。

- **Grok Bot**：带一台云端电脑、能替你操作网站和应用的 AI 队友。只在 Premium、Super、Ultra（和团队版、企业版）里有，Plus 和 Free 都不含。
- **AI 图片和视频**：免费版不能生成视频；Premium 页面写明可以生成 AI 图片和视频。
- **写代码相关**：代码托管、AI 代码审查、云端 agent 和自动化从 Premium 开始。
- **Super 多出的**：高峰时段优先使用模型。**Ultra 多出的**：最早用上新产品和新模型、优先支持。

## X 会员区别：Plus 和 Premium 的 X 权益不一样

结论：X 权益也是 Grok 套餐区别的一部分，想要完整 X Premium+ 权益，至少选 Premium。

- X 权益要先把订阅**连接到个人 X 账号**才生效，组织账号、附属账号不行。
- Plus：Premium 认证勾、时间线广告更少、创作者工具、高级数据分析。
- Premium 及以上：完整 X Premium+ 权益，包括大部分页面无广告、优先挑选 @用户名、回复更容易被看到。
- 原来是 X Premium+ 的人想保留这些权益，要选 Premium 或以上。

## 老套餐对应关系：SuperGrok、X Premium、Cursor

结论：老套餐还能续，但新用户只能在四档里选。下表是官方给的对照，不同老套餐的 Grok 套餐区别对照方式不一样。

**Cursor 老套餐**（官方原话：对照的是“最接近”的档位，不是完全一样）：

| Cursor 老套餐 | 价格 | 最接近的新档位 |
|---|---|---|
| Hobby | 免费 | Free |
| Pro | $20/月 | Premium |
| Pro+ | $60/月 | Super |
| Ultra | $200/月 | Ultra |
| Teams Standard | $40/人/月 | Teams Premium 席位 |
| Teams Premium | $120/人/月 | Teams Super 席位 |

印度另有 Start 套餐（₹649/月含税），对应 Plus。

**SuperGrok 老套餐**：官方没有给出和新四档的对照表。能查到的只有 Grok Bot 用量上的等级对照：SuperGrok 和 X Premium+ 与 Cursor Pro 同档，SuperGrok Plus 与 Cursor Pro+ 同档，SuperGrok Heavy 与 Cursor Ultra 同档；SuperGrok Lite 不含 Grok Bot。详见 [SuperGrok Heavy 是什么](supergrok-heavy.md)。

**X Premium 老用户**：要保留 Premium+ 权益就换 Premium 或以上。

换不换自己决定。换过去以后，就按上面总表里的 Grok 套餐区别享受新权益；一旦换了不能撤销，老套餐按剩余时间自动退款。

## 国内用户看 Grok 套餐区别要注意什么

## 常见问题

### Grok 会员对比下来，新手选哪档？

官方建议刚开始用 AI 的选 Premium，每天用 agent 的选 Super，重度用户选 Ultra，AI 用得少的社交创作者选 Plus。

### Grok 订阅区别里，Plus 和 Premium 差多少？

月费差 $22。Premium 多了 4 倍用量、Grok Bot、视频生成、代码托管和完整 X Premium+ 权益。

### Super 和 Ultra 的 Grok 套餐区别只有用量吗？

Ultra 多了最早体验新产品和新模型、优先支持，其余和 Super 一样。

### Grok 套餐区别以后还会变吗？

可能会。官方写明价格可能变动，本文按 2026-10-16 的官方页面整理，下单前以 x.ai/pricing 为准。
